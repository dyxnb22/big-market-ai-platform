# Archive docs

Files under `docs/archive/` are **historical snapshots** retained for context only.

They are **not** evidence of current-HEAD readiness, closed-loop demo status, or production claims. Prefer:

- `docs/MICROSERVICES.md`
- `docs/operations-checklist.md`
- `docs/data-and-outbox.md`
- `AGENTS.md` / `docs/learning/` (final-state guides)

When a statement in an archive file conflicts with code, config, or Docker init SQL, trust the living tree and update authoritative docs — do not cite archive markdown in PR acceptance.
