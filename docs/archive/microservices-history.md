## Retained Learning Value

- Service boundaries should be described from code paths, not from migration
  status.
- DDL, MQ, jobs, monitoring, acceptance, rollback, and cleanup belong in
  operational learning docs.
- Local completion is proven through build, smoke tests, guardrail scripts, and
  code/documentation consistency.
